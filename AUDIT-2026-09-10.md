- `hooks/before_prompt.py`: removed unused `import re`.

## Full Review Findings

Ranked by impact. Read-only; no changes made.

1. **[High — correctness] Call edges point at non-existent source nodes.** `src/ckg/graph/parser.py:216` adds `call_edges.add((f"sym:{f_rel}::{name}", target))`, using the *callee's short name* as the source node, not the enclosing caller symbol. Measured on the fixture: **7 of 29 edges (24%) have a `src` that is not a node** (`sym:core.py::connect_db`, `sym:utils/db.py::is_connected`, …). Downstream code partly hides this (`hybrid._memory_neighborhood` guards `if src in adj`; the PGQ path filters by neighbor set), but `ckg build`/`ckg load` persist a graph with ~quarter of its edges dangling. Fix requires capturing the caller's qualified symbol during pass 2 and would change graph output → needs approval.
2. **[Med-High — robustness] Enrichment crashes on unparsable files.** `parse_tree` tolerates `SyntaxError` (`parser.py` pass 1), but `enrich_node_text` calls `ast.parse` at `builder.py:107` and `builder.py:141` with no handler, so one syntactically-invalid `.py` raises out of `ckg build` and out of the background auto-build (`context.ts` → `ckg build`). Recommended: wrap both in `except SyntaxError: return node`.
3. **[Med — correctness] Project-level injection toggle is ignored on the injection path.** `pi/extensions/ckg/context.ts:78` calls `loadSettings()` with no project root, so `.ckg/pi.json` `inject:false` is ignored, while the HUD (`hud.ts:35`, `context.ts:130`) passes `projectRoot` and honors it. The Claude hook (`hooks/before_prompt.py:67`) *does* read the project config. Inconsistent gating across surfaces.
4. **[Med — test hygiene] Running pytest dirties tracked files.** `tests/conftest.py:16-59` creates a nested git repo in `tests/fixtures/sample_project/` and appends comment lines to three tracked fixture files. Observed during this audit (`git status` showed `M tests/fixtures/sample_project/sample_pkg/{core.py,utils/db.py,utils/helpers.py}`), requiring a manual `git checkout --` before committing. Recommended: build the fixture in `tmp_path`, or commit the intended file content and generate only git history.
5. **[Med — dependency/config hygiene] Declared dependencies and config are never used.** `pyproject.toml:20,22,23,24` declare `pyyaml`, `oracleagentmemory`, `langchain-oracledb`, `langgraph-oracledb`; no module under `src/` imports any of them (the storage layer is duck-typed on `mem._pool`). `configs/default.yaml` is also dead: no code imports `yaml` or reads that file, yet README:372/458 and the file itself document it as the config surface. Removing them requires a `pyproject.toml`/`uv.lock` change → documented only.
6. **[Low — maintainability] Dead call-resolution logic.** `parser.py:63` `_resolve_call_target(..., sym_by_name, ...)` is always called with `{}` (`parser.py:209`), so its first branch is unreachable; the caller's fallback loop at `parser.py:209-213` can never add a target because `mod_targets` already contains every `sym:{rel}::{short}` id. Confusing but currently harmless.
7. **[Low — consistency] Cache written two different ways.** `claude/plugin.py:60-72` writes `.ckg/code_graph.json` with `json.dumps(graph, indent=2)` while `cli/main.py:53` uses `sort_keys=True`; switching build paths churns the cache file.
8. **[Low — hygiene] Module-level HUD state.** `pi/extensions/ckg/hud.ts:99` keeps a single `_last` across sessions/projects; a fresh project whose rendered text matches the previous one skips the first `setStatus`.
9. **[Low — hygiene] Dead exported/test surface.** `pi/extensions/ckg/cli.ts:9` `CliCommand` type has no in-repo use; `tests/conftest.py:112` `load_graph_json` is unused; `.pi/subagents/**` (tracked) holds stale agent artifacts, and `.pi/` is not in `.gitignore`.
10. **[Low — observability] Broad exception swallowing.** `connection.py:107,138,167` and `oracle_pgq.py:63` catch all exceptions by design (never-raise contracts) but discard type/detail; acceptable given the module docstrings, worth a debug log.

## Remaining Risks

- **Live Oracle path unverified.** The 11 skipped live tests were not run. Valid *accepted* identifiers were only checked by unit test, not against a real `CREATE/DROP PROPERTY GRAPH` or `GRAPH_TABLE` server; the rejection-before-SQL behavior is fully tested.
- **A behavior change for invalid config is possible but intentional:** an unreachable/garbled `CKG_ORACLE_GRAPH`/`CKG_ORACLE_TABLE_PREFIX` now raises `ValueError` inside `match_*`, which `hybrid_retrieve` catches and degrades to in-memory mode with a hint — same fallback direction as before, different message. Schema-qualified graph names remain accepted.
- **TypeScript reviewed statically only** — no compiler/linter available offline, so the import-only deslop edits were not machine-verified. Changes are import-list/constant-literal only.
- **Prompt-injection (Medium) and default-credential (Medium) findings are deferred** by design; both need a product decision.
- **Test-suite side effect:** `tests/fixtures/sample_project/.git` now exists locally (untracked) from the baseline/after runs; it is not part of any commit. Clean checkout behavior is unchanged.
- **Scan false positives dismissed without code change:** 11 `sql_string_concat` (9 benign/test + 2 now validated), 6 `bare_except_pass`, 3 `subprocess_list_no_check`, 6 `ts_ignore`, 1 `console_log_prod`, 7 `hardcoded_localhost_port`.
